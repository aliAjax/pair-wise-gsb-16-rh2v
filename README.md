# hxwl-01 听力验配记录

门店听力师的验配档案与听力曲线工作台

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5101

## 功能

- 新增初配档案：登记左右耳气导、骨导（250–8000Hz）、言语识别率与助听器参数（型号、机型、验配公式、各频率增益、MPO）
- 同一客户已有进行中的初配时自动打开旧档案，不重复建档
- 初配保存为基线；复诊在旧参数上修改并追加记录，基线听阈与增益永久保留
- 档案列表按复诊状态（初配进行中 / 复诊跟进 / 已结案）和听损类型（感音神经性 / 传导性 / 混合性）筛选，支持姓名、电话搜索
- 档案详情页对照基线与当前值：听力曲线图、听阈/增益明细表（含变化量）、历次就诊时间线
- 数据保存在浏览器 localStorage，重新打开页面仍可看到新增档案与历次复诊
